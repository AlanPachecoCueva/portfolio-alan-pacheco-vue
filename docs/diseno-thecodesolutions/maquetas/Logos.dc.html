Logo — tres direcciones

Cada propuesta tiene isotipo (el símbolo, que sirve de favicon e ícono de redes) y logotipo (el nombre). El color de acento se cambia en Tweaks para probarlas con cada paleta.

Idea: los corchetes de una etiqueta de código con un check dentro, es decir, código que resuelve. Es la más directa y la que mejor se lee como favicon. Riesgo: el símbolo </> es común en marcas tech; el check lo diferencia.
